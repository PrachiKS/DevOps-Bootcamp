# Day 01 - DevOps Mindset

## Ticket
Ticket #0001 - Why DevOps?

## Objective

Understand why companies need DevOps after software development.

## What I Learned

- Developers write application code.
- DevOps engineers automate, deploy, monitor, and maintain applications.
- Code running only on a developer's laptop is not enough.
- DevOps helps deliver software reliably and consistently.

## Key Takeaway

DevOps bridges development and operations by automating the software delivery process.
