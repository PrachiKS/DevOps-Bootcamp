2. Docker Image vs Container
Docker Image

An image is a read-only template used to create containers.

Example:

docker images

The hello-world image was downloaded from Docker Hub.

Docker Container

A container is an instance created from an image.

Example:

docker ps -a

The hello-world image created a container named festive_moore.

5. Container Lifecycle

Practiced the following commands:

Run
docker run

Creates and starts a new container.

List Running Containers
docker ps

Shows currently running containers.

List All Containers
docker ps -a

Shows running and stopped containers.

Stop
docker stop <container>

Stops a running container without removing it.

Start
docker start <container>

Starts an existing stopped container.

Restart
docker restart <container>

Stops and starts an existing container.

Remove
docker rm <container>

Removes a container.

6. Background Containers

Created an Ubuntu container that runs in the background:

docker run -d --name my-ubuntu ubuntu sleep 300

Verified it using:

docker ps

The container appeared with an Up status.

7. Inspect Containers

Used:

docker inspect my-ubuntu

This displays detailed JSON configuration and runtime information.

Important fields observed:

Container ID
Container state
Exit code
Image
Container name
Network configuration
Mounts
Command

Used formatted output to extract specific information:

docker inspect --format='{{.State.Status}}' my-ubuntu

Output:

exited

And:

docker inspect --format='{{.Config.Image}}' my-ubuntu

Output:

ubuntu
Key Learning

docker inspect is useful for troubleshooting and extracting configuration details from containers.

8. Container Logs

Viewed container logs using:

docker logs festive_moore

This displayed the output generated by the hello-world container.

Also practiced real-time log monitoring:

docker logs -f log-demo

The -f option follows the log output and displays new messages as they are generated.

This is similar to:

tail -f app.log

in Linux.

DevOps Use Case

When a containerized application fails or behaves unexpectedly, checking its logs is one of the first troubleshooting steps.

Interview Concepts
What is a Docker image?

A Docker image is a read-only template used to create containers.

What is a Docker container?

A container is an isolated runtime environment created from a Docker image.

Difference between docker run and docker start

docker run creates and starts a new container.

docker start starts an existing stopped container.

Difference between docker stop and docker rm

docker stop stops a container but keeps it.

docker rm removes the container.

What does docker ps show?

It shows currently running containers.

What does docker ps -a show?

It shows all containers, including stopped containers.

How do you check container logs?
docker logs <container_name>
What does -d mean?

-d runs a container in detached/background mode.
